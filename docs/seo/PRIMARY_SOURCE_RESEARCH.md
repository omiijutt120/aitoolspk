# Primary-source research register

Checked **23 October 2026, Asia/Karachi**. These are read-only documentation findings for the enterprise implementation. They are not evidence of a Search Console login, indexed URL, rich result, commercial authorization, real-user performance result or deployment. Public documentation was opened with the available web tool; the Sitemaps help page timed out once with `?hl=en`, then its unparameterized URL opened successfully. Source dates below are page dates where explicitly shown, rather than guesses from search snippets.

## Evidence hierarchy and limits

Use these sources to assess policy and implementation design. Use the actual crawl, static export, browser report, public catalog and approved private review process to assess this site. Official documentation cannot supply this property's clicks, impressions, indexed count, chosen canonical, manual-action status or commercial rights. Unknown values remain null, not zero. The owner's original 811-stock confirmation does not complete commercial review. The six newer offers have a generic verbal eligibility confirmation, but the requested brand-specific delivery/authorization details have not been supplied.

No GSC account was read or modified here; no DNS, crawler policy, GA4 collector, old-domain redirect or publication was performed. Ahrefs, Similarweb and Firecrawl directory discovery returned unavailable/not installed in the parent audit; do not treat proposed uses as successful integration calls. Recheck changing documentation before the next release or account operation.
