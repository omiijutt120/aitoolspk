# Complete product coverage

Measured from sanitized data on 23 October 2026: **817/817 offers (100%)**, 108 primary collections, 13 categories. Every public ID has exactly one JSON record and CSV row, a stable offer URL, an unchanged listed PKR price and a primary collection/keyword target.

| APPROVED_INDEXABLE    |      0 |
| INFORMATIONAL_NOINDEX |      0 |
| NEEDS_REVIEW          |    817 |
| EXCLUDED              |      0 |

These are governance states, not Google index-status measurements. All 817 commercial approvals are pending. Original 811 stock records retain the owner's in-stock confirmation; six premium plans remain stock-unconfirmed. Verbal confirmation without the promised delivery/authorization details does not manufacture evidence. No approval file or price was changed to improve coverage.

Generated private outputs:

- `reports/seo/product-seo-master.json` and `.csv`: every ID, identity, exact listed/approved price distinction, listed terms, keyword candidates, sources, metadata, publication decision, content fingerprint, quality, freshness, commercial checks and unknown metrics.
- `collection-seo-master.json`, `keyword-to-url.{json,csv}`, `search-intent-clusters.json`: parent/variant relationships and deliberate shared-intent targets.
- `approval-blockers.json`, `quality-checks.json`, `content-refresh-priorities.json`: missing evidence, duplicate descriptions and next actions.
- `internal-link-recommendations.json`, `page-indexability-matrix.{json,csv}` and `local-technical-audit.json`: final export/navigation/indexing agreement.
- `serp-opportunities.csv`: actual dated public research, not invented SERP ranks.

Public research covers **16 collections /320 offers** through 24 source observations. Remaining 92 collections /497 offers receive explicit hypothesis-only candidates and research specifications. This is complete catalog analysis, **not** a claim of individual demand research for all 817 offers. Volume, difficulty, CPC, backlinks, search visibility and conversions remain null without real evidence.

The heuristic flags **788 offers** with another same-parent identical normalized description; no additional near-description matches exceed the five-word-shingle threshold. This reflects generic catalog wording, not 788 independently proven Google penalties. Review differentiated terms before changing indexing. **215 offers** have honest text-brand fallbacks; do not fabricate logos. Missing licensed official assets are prioritized separately.

Automated coverage fails on duplicate/missing identity, invalid retail price, unknown editorial IDs, missing routes, orphan pages, incorrect canonical/OG, schema/publication disagreement, noindex sitemap entries or duplicate indexable metadata. It checks all offers, not a top-product sample. Original 811 facts also retain the exact preservation SHA fixture. Changed/added/removed IDs are reported against the previous ignored snapshot; a second unchanged run is expected to show no changes.

Run `npm run seo:products` for source coverage and `npm run seo:validate` after a fresh build for rendered evidence. Report timestamps distinguish current local HTML from older production.
