## New deliverables and reproducible commands

- `PRODUCT_VERIFICATION_QUEUE.csv`: all 815 pending offers, with 30 verification priorities at top. Rank means **review order**, not verified demand, stock or resale rights. Blank cells are intentionally unknown.
- `PRODUCT_PRICE_FRESHNESS_REPORT.csv`: all 817 records, original price and quote date, age and seven-day stale test. It does **not** refresh any quote.
- `COMPLETE_URL_AUDIT.csv`: 1,006 locally exported HTML routes with canonical, metadata, robots, sitemap membership, H1 count, schema types and incoming-link count. The local validation found 188 indexable/sitemap URLs and zero errors; these are static-export findings, not Google index status or 1,006 live HTTP checks.
- `COMPLETE_LIVE_URL_AUDIT.csv`: 1,003 live public URLs discovered from the sitemap and native internal links, with HTTP status, final URL, canonical, title, description, robots, H1, schema types and body bytes. The crawl finished at 21:01 UTC on 18 November (02:01 Pakistan time on 19 November), with 0 page errors and no 1,500-URL crawl cap. Assets, rendered JavaScript, redirect chains and Core Web Vitals are outside this native-HTML crawl.
- `KEYWORD_URL_MAPPING.csv`: 817 offer-level candidate query assignments generated from the existing research model. The `evidenceStatus` field distinguishes researched clusters from unmeasured exact-query demand. Repeated parent targets are intentional while offers remain unapproved; the [keyword strategy](KEYWORD_STRATEGY.md) explains page ownership. No search volume or ranking was invented.
- `npm run catalog:quote-request`: writes `reports/quotes/quote-request.csv` for the seller. Existing `catalog:quote-apply` validates returns but does not approve SEO publication.
- `npm run gsc:export -- --days 7 --out reports/gsc/7d` (repeat for 28 and 90): when a read-only GSC credential is available, exports true query-page pairs, country, device and search appearance alongside the existing daily/query/page tables. The API returns top rows and may omit low-volume queries.
- `npm run gsc:analyze -- --dir reports/gsc/owner-export`: offline alternative when `queries.csv` is provided; optional `daily.csv` allows explicit unreported-query reconciliation. Accepts standard English GSC `Top queries` or this repo's `query` header. All classifications are heuristic candidates; unclassified remains separate.
- `npm run seo:discovery -- --all`: live complete sitemap scan, now including opaque token detection in each page body.

The 19 November local `launch:check` passed: 130 unit tests at the time of that run, 1,006 exported pages, 72,691 internal references, zero broken targets, zero confidential fields, zero opaque token pages, 188 sitemap URLs, and 1,501 valid fragment references. A subsequent clean `npm ci` and full `npm test` passed **132/132** tests after the final reporting changes; the production dependency audit found **zero** vulnerabilities. Playwright passed **88/88** browser tests. The live discovery run passed **14/14** checks across all 188 sitemap URLs, and the 1,003-page broader live crawl passed with zero page errors.

The Search Console UI equivalent is Performance → Search results → Web → Queries → Add filter → Custom (regex) → **Doesn't match regex** → `(?i)^ai[0-9]+$`. Keep the matching group in a separate report. Google may suppress anonymized queries, so filtered and unfiltered totals need not add exactly. For attribution, apply a Page filter and export its Queries table, or use the paired `query-pages.csv`; do not pair independent exports.
