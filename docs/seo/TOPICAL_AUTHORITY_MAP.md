Every eligible offer links to its primary collection and category. Detail pages now provide native links to both practical buying guides. Guides link back to relevant parents/categories, not arbitrary unrelated pages. Existing priority collection guides contain vendor-source links and selection questions on their first page; pagination avoids repeating their full introduction.

Generated `internal-link-recommendations.json` provides three explicit destinations and reasons for every offer. Validation checks those targets exist and counts actual incoming links from rendered HTML. Recommendations are not silently claimed as measured improvements. Use the generated graph to add contextual links only where the paragraph helps a reader.

Do not create 817 near-identical articles, city-spun pages, empty comparisons, stock-only landing pages or machine-translated Urdu duplicates. A new guide needs a distinct question, a real evidence trail, an accountable editorial review and useful information beyond the existing comparison inventory. Evaluate Urdu demand and maintainable editing before adding a locale or hreflang.

Success is measured after an authorized release using comparable GSC query/page windows, eligible indexed coverage, qualified enquiry evidence and task completion. Counts of published pages, generic authority scores and unobserved AI citations are not substitutes for those outcomes.
